## Overview

The app is the main user-facing SPA:

- Client-side rendered (no SSR)
- File-based routing via TanStack Router
- tRPC client for API communication
- Better Auth client for session management
- Deployed as Cloudflare Worker with static assets

**Port (dev):** 5173 (Vite default)

## Tech Stack

| Layer        | Technology                                             |
| ------------ | ------------------------------------------------------ |
| Framework    | React 19                                               |
| Routing      | TanStack Router (file-based)                           |
| Server State | TanStack Query + tRPC                                  |
| Client State | Jotai                                                  |
| UI           | shadcn/ui (new-york), Tailwind CSS v4                  |
| Auth         | Better Auth client (passkey, Stripe)                   |
| Build        | Vite (SWC, code splitting: react, tanstack, ui chunks) |
| Testing      | Vitest, Happy DOM                                      |

## TanStack Query Defaults

- `staleTime: 2min`, `gcTime: 5min`, `retry: 3` (exponential backoff)
- Mutations: `retry: 1`, error logging
- Route preloading: `defaultPreload: "intent"` (prefetch on hover)

## Vite Dev Proxy

API requests `/api/*` proxied to backend during dev; forwards `x-forwarded-origin` header.

## Path Aliases

Use `~/` prefix for imports within the app:

```typescript
import { Button } from "~/components/ui/button";

```

## When Working Here

1. **Adding a page**: Create file in `routes/`, TanStack Router auto-generates route tree
2. **Protected page**: Place in `routes/(app)/` — auth guard runs automatically via `beforeLoad`
3. **API calls**: Use tRPC hooks (`trpc.routerName.procedureName.useQuery()`)
4. **UI components**: Import from `@repo/ui` (shadcn/ui workspace package)
5. **Never edit**: `lib/routeTree.gen.ts` (auto-generated by TanStack Router)
6. **Adding state**: Prefer server state (TanStack Query) over client state. Use Jotai only for UI state.
